## Integración y límites

No se observó un embed público verificable de Sender ni IDs de sus formularios. La web usa formularios de Elementor y MailOptin. No puede deducirse que todas las acciones terminen en Sender. El envío, mensajes de éxito, validación del servidor, grupos y automatizaciones quedan sin verificar. No hubo envíos reales. Los consentimientos son los campos observados arriba; si no aparece checkbox no se inventa una autorización.

Para activar: obtener el snippet oficial JavaScript y el div sender-form-field con data-sender-form-id desde Sender, identificar grupo, finalidad, campos, consentimiento, doble opt-in, página de gracias y automatizaciones de cada formulario. Documentación oficial: https://www.sender.net/help/lead-capture/how-to-embed-a-form-on-a-website-builder/ y https://www.sender.net/help/lead-capture/form-troubleshooting/. Nunca usar una API key privada desde el navegador.
